# Seguridad, privacidad y manejo de evidencias

- Por defecto, usar repositorios **privados** para trabajo estudiantil; compartir por invitación.
- Usar alias de GitHub en vez de matrícula, teléfono, correo o respuestas a encuestas.
- Evitar subir rostros o voces sin consentimiento y autorización institucional correspondiente.
- Nunca guardar tokens, contraseñas, claves Wi-Fi, información de acceso a plataformas o secretos en el repositorio; usar archivos locales ignorados por Git.
- Guardar videos grandes y registros voluminosos en una carpeta institucional de acceso controlado. En GitHub conservar vínculos y metadatos.
- Mini-sumo y seguidor: nunca manipular cableado energizado; implementar paro seguro y límites de motor.
- Tello: supervisor presente, espacio interior despejado, verificación de batería, procedimiento de emergencia y compatibilidad real del modelo/SDK.
- AMR: zona delimitada, límites de velocidad, mecanismo de paro y protecciones existentes habilitadas; no anular sensores de seguridad.
- Verificar el reglamento del evento y las condiciones institucionales antes de publicar fotos, planos, códigos o imágenes.
