# Alcances seleccionados por el equipo

Usar solo **los alcances elegidos** del [Catálogo C2](https://docs.google.com/document/d/1IKU_tOalci97s1IAPSAro_Fr8bkX28CUhWJaSbukDkE/edit).

Para cada alcance, **copiar** `alcances/_plantilla-alcance/` como por ejemplo `alcances/MS01-chasis/`, `alcances/TL06-deteccion-color/`.

| Código | Título | Persona responsable | Estado | Evidencia |
|---|---|---|---|---|
| | | | Planeado / En prueba / Validado | |

Cada alcance tiene un solo README de diseño y tres katas progresivos que pueden reutilizarse como guía. El catálogo contiene 48 posibles alcances: **no es necesario crear las 48 carpetas dentro de un repositorio de equipo**.
