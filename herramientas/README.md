# Configurador de misión · Mission Forge C2

Abre [`mission-forge-c2.html`](mission-forge-c2.html) en tu navegador **después de descargarlo** (no hace falta internet). Elige tu plataforma, de uno a tres alcances y los katas que te ayudarán a demostrar tu frontera.

Al terminar, usa **Descargar mi kit .md**. Renombra ese archivo a `compromiso.md` y colócalo en `participantes/<tu-alias>/compromiso.md` dentro de tu copia del repositorio.

El configurador no envía ni sincroniza datos con GitHub ni con Drive. Cada participante debe subir su propio archivo al repositorio privado del equipo. No registrar matrículas ni datos sensibles.

**Catálogo fuente:** [Catálogo C2 Google Sheets](https://docs.google.com/spreadsheets/d/1FKxFzoyu9KJb3RlOwB609vliS5hAtmwWFu2G2zG3Ky4/edit).
